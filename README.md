# Personal Coach

A diet and training tracker with a built-in rule-based coach. Built with Expo
(React Native + TypeScript) and runs in the browser on your laptop.

## Run it (macOS)

1. Install Node.js LTS from https://nodejs.org.
2. In Terminal, from this folder:

   ```bash
   npm install
   npm run web
   ```

3. Your browser opens the app at http://localhost:8081.

## Other commands

```bash
npm test             # unit tests
npm run typecheck    # TypeScript check
npm run build:web    # production web build into dist/
```
